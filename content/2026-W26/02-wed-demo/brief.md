## Concept
Show a Filipino teacher how to use Gemini to make a complete lesson plan in under 3 minutes — from blank page to ready-to-use outline. Real prompt, real output on screen.

## Structure
- Hook (0–5s): "Mga Guro — ilang oras ang ginagastos mo sa lesson plan? Panoorin ito."
- Setup (5–15s): Open gemini.google.com — log in sa Gmail, libre, walang bayad
- Demo (15–55s): Type prompt → show output → highlight: grade level, objectives, activities, assessment — all in one go
- The point (55–75s): "Dati isang oras. Ngayon, tatlong minuto. Pwede mo na gamitin yung nakatipid na oras para sa students mo."
- CTA: "I-comment ang iyong subject — ipapakita ko ang exact prompt para sa 'yo."

## Prompt to demo on screen
```
Gumawa ng lesson plan para sa Grade 4 Filipino — paksa: Paggamit ng Pang-uri. 
45 minuto. Isama ang: layunin, panimula, gawain, pagtataya.
Tagalog lang.
```

## Why this works
- Guro audience is massive (900K+ PH teachers) and underserved by AI content
- Specific persona + specific task = high save rate
- Comment CTA drives direct engagement — "anong subject mo?" is easy to answer
- Shows free tool + Gmail login = removes biggest barrier ("may bayad ba?")
