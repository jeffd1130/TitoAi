## Visual signature

- **Dark navy background** — dominant. Never white, never light.
- **Gold accent** — headlines, lines, logo elements
- **Hero media in framed window** — not full-bleed; breathing room above and below
- **Bebas Neue bold headline** — large, white, takes upper portion of frame
- **Warm, human** — Jeff at home, natural light, real setting
- **No stock photos.** Always real: real screen, real Jeff, real output.

## Voice

| Element | Rule |
|---------|------|
| Language | Taglish — natural mix, not forced |
| Tone | Warm older kuya/tito — never lecturing |
| Length | 60–90 sec max for TikTok. Never over. |
| Proof | Always show real output. No stock clips. |
| CTA | Always end with follow + Tito AI name |
| Energy | Calm confidence — hindi parang nagbebenta |

## What NOT to say / show

- No pure English captions (keep it Taglish)
- No paid tool recommendations — free tools only
- No "you need a high-end laptop" framing
- No corporate tone — this is a Tito talking to his Pamangkin
- Don't lead with "48 years old" — lead with "Household dad"
