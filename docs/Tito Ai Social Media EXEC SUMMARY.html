Key Findings
01
Named persona + step-by-step + free tool = the top format
Posts that name who it's for (VA, Guro, Negosyante) and show one free tool doing one job consistently outperform everything else on both platforms.
02
Carousels generate stronger engagement signals than reels
Every swipe is logged as an interaction. TikTok's algorithm reads this as quality content and distributes further - reels don't produce the same signal depth.
03
Boosted posts convert followers - organic still needs testing
348 net new followers this week came primarily from a boosted story reel (S1E2 Pares Clark). Organic carousels convert at ~3 followers per 349 views. Boost strategy is working; organic conversion still needs sharpening.
04
Slide text is indexed by TikTok search
Search traffic is appearing organically for niche queries. Text in carousel slides gets read by the algorithm - this is a compounding SEO-style advantage reels don't have.
05
One niche (Guro) is too narrow - broad persona unlocks scale
VA, freelancers, negosyante, and employees are all searching for the same AI tips. Rotating personas expands reach without changing the content format that already works.
06
Branded search is appearing - TitoSerye playlist needed now
"Titoserye Filipino ai" is being searched. No playlist exists to capture it. Creating a TitoSerye collection this week will retain viewers who arrive via search and turn them into followers.
