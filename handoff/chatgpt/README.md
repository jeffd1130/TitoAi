# ChatGPT → Claude Code handoff inbox

ChatGPT/Codex drops finished generations here. Claude Code owns the finish (review, captions, edit, docs). Jeff approves and posts.

**ChatGPT: how to hand off**
1. Generate the clip in **Google Flow first** (Veo 3.1 Lite, 9:16, x1, "Return silent videos" ON). Use Gemini only after the day's Flow credits run out.
2. Save the video here with a clear name, e.g. `origin-part-3-flow.mp4`.
3. Save a note with the **same name** and `.md`, e.g. `origin-part-3-flow.md`, covering:
   - what it is for (post, week/slot, part)
   - the tool and model, and the exact prompt used
   - anything Claude should check or fix
4. Stop there. Don't edit captions, `docs/schedule.json`, the Remotion source or `CLAUDE.md`. Claude Code finishes those.

Tito AI Studio shows new files on the **Board** (frame "ChatGPT → Claude handoff"). Jeff presses **Hand to Claude**, and Tito AI (chief of staff) reviews the frames for chibi consistency, then places, captions, renders and sends it to QA, or says what to regenerate.
